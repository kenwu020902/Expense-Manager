# 💰 SplitExpense Tracker

A simple web app to track and split expenses between friends or groups.

## ✨ Features
- Add expenses with description and amount
- Automatically calculates who owes whom
- Data saved in browser (localStorage)
- Delete expenses
- Simple equal splitting between 3 people

## 🚀 How to Use
1. Open `frontend/index.html` in browser
2. Enter expense description and amount
3. Click "Add Expense"
4. View balances below
