# Simple Expense Tracker

A basic web app to track and split expenses between friends.

## Features
- Add expenses with description and amount
- Track who paid
- Automatically calculates who owes what
- Data saved in browser

## How to Use
1. Open `index.html` in any browser
2. Add expenses using the form
3. View balances below

## Technologies
- HTML
- CSS
- JavaScript
- localStorage
