# Trip Planner & Expense Tracker

A complete web application for planning trips, tracking expenses, and splitting bills between friends.

## Features
- **Trip Planning**: Set dates, destinations, and descriptions
- **Participant Management**: Add people with budgets and preferred currencies
- **Activity Planning**: Plan activities with selective participation
- **Expense Tracking**: Track expenses with categories and splits
- **Currency Converter**: Convert between 5 currencies
- **Balance Calculations**: See who owes whom automatically
- **Calendar Export**: Add trips to your device calendar
- **Budget Checking**: Warn if participants exceed budget
- **Real-time Balances**: See balance impact as you type
